# React-to-Compose frontend audit (work in progress)

This inventory is generated from the pre-migration source tree. The native implementation is **not yet feature-complete**: the original web UI has been removed and native route coverage is in place, but native interactions and component parity must be audited and tested before this branch can replace production.

Native systems: AndroidX Compose, M3 Expressive colour/type/shapes/motion, Navigation Compose, adaptive NavigationSuite, encrypted Android Keystore credentials, isolated SDK WebMessage bridge.

**Known unfinished features:** fully formatted Markdown and code highlighting, attachments/pickers, virtualized transcript semantics, permission option parity, queued messages interface, session rewind UI, enhanced mission features/workers views, X25519 relay secure channel, terminal ANSI rendering, advanced Git diff viewer, custom model/provider forms, complete MCP OAuth, plugin management forms, automation run history display, secure biometric lock, background service and push alerts, notifications, two-language UI localisation, app settings refresh/recomposition. Do not merge until these are implemented and live-tested.
